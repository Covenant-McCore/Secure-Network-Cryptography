System Overview

The problem

Digital organizations — hospitals, universities, financial institutions, government agencies — exchange sensitive information across public networks. This creates a set of well-known security requirements: confidentiality, integrity, authentication, authorization, secure key establishment, and auditability. Traditional cryptographic tooling addresses some of these, but emerging threats (in particular quantum computing) require the adoption of post-quantum primitives.

The approach

CRYPTO-NET integrates five cryptographic primitives into a single web-based platform:

  • AES-256-GCM for authenticated symmetric encryption
  • ML-KEM-768 for post-quantum key establishment
  • HKDF-SHA-256 for session-key derivation
  • Ed25519 for digital signatures
  • CP-ABE (BSW07) for policy-based access control

Case environment

The platform is generic to any digital organization. A healthcare organization is used as the demonstration environment, with the following roles: Administrator, Security Officer, Doctor, Records Officer, Laboratory Officer.

What is demonstrated

  1. User authentication and role-based authorization
  2. Post-quantum secure key establishment between two users
  3. End-to-end encrypted messaging with integrity verification
  4. Secure file transfer with SHA-256 fingerprints
  5. Digital signatures for message authenticity
  6. Policy-based access control over encrypted data
  7. Audit logging and security monitoring
  8. Controlled threat simulations
